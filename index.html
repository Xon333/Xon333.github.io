t3code

Personal tools operated by Otis Heric for organizing saved resources and reviewing information from his own Google account.

Google-connected workflows

The existing clients are Library-boopmark and YouTube Read Access. The separate YouTube read workflow retrieves account, channel, subscription and playlist information with read-only access. An owner-requested Google Data Portability export covers YouTube activity for personal review.

Library organizes bookmarks and can use OpenAI to suggest descriptions and subjects. Its direct YouTube connector is proposed work and is not currently installed.

Access and privacy

These pages describe the personal application. The working tools use private access; there is no public sign-up here.

Privacy policy

Updated 14 November 2026.

Stanza is a personal application operated by Otis H. Z. This policy covers its private workspace and separate Google workflows.

Data and purpose

Ongoing Google access is limited to YouTube read-only access for playlist videos, channel information, subscriptions and playlist metadata. It does not authorize changes to your YouTube account. The feed also retrieves X bookmarks through the existing X connection.

A completed one-off YouTube activity export is retained separately for private analysis. Future Data Portability requests have been retired. Historical activity is not automatically added to the feed or used to change Seen state. Watch Later, when captured separately, remains a separate private list.

The workspace stores saved links, content, notes, feed metadata and classifications. Saving a feed item to the library is an explicit action. Workspace access remains private.

Storage and processing

The original Google credentials and historical exports are stored on the operator’s Mac, protected by FileVault and restricted file permissions. The connector also uses private server credentials. Workspace data is stored on a private server; server-wide disk encryption is not implemented. Application encryption of model keys does not encrypt all workspace data or backups.

Feed evaluation can send incoming X and YouTube URLs, titles and descriptions to OpenAI before an item is saved. Requests can include subject guidance and selected reviewed library examples. Saved-resource classification can also send captured text and a limited note excerpt. Provider retention terms apply; requesting store: false does not guarantee zero retention. No model calls are part of the historical import.

Google and X receive authorization and retrieval requests. GitHub Pages receives ordinary website request metadata. These public pages use no analytics, remote fonts, forms or sign-in scripts.

Retention and deletion

Raw historical exports and temporary read results become eligible for manual deletion 30 days after successful import or explicit review approving disposal. Pending or held artifacts are preserved. Cleanup is manually triggered; there is no scheduled deletion job. Selected datasets and saved workspace content remain until deliberately deleted.

To request deletion, email mail@otishz.com. Local deletion does not erase every backup, snapshot or provider-held copy. Backup and provider retention vary; no universal deletion deadline is guaranteed.

Revoke future Google access through Google Account connections. Revocation does not delete copies already stored.

Privacy policy

Updated 14 November 2026.

Stanza is a personal application operated by Otis H. Z. This policy covers its private workspace and separate Google workflows.

Data and purpose

YouTube read-only access retrieves channel information, subscriptions and playlist metadata for personal review. Data Portability access requests a copy of YouTube activity. These permissions do not authorize subscription or playlist changes.

The workspace stores saved links, content, notes and classifications. It uses local sign-in. Its Feed interface is installed; direct Google retrieval and import into the workspace are not implemented.

Storage and processing

Google credentials and retrieved results are stored on the operator’s Mac. Workspace data is stored on a private server. Credential files have owner-only permissions and workspace model keys are encrypted; encryption of all stored data and backups has not been verified.

Optional classification sends resource URLs, titles, descriptions, captured text, a limited note excerpt, subjects and selected examples to OpenAI. Other model providers can be configured. Provider retention terms apply; requesting store: false does not guarantee zero retention.

The review has not established that Google exports or subscription results are sent to a model provider. If Google-derived material is saved and classified, it may enter the processing described above.

Google receives authorization and API requests. GitHub Pages receives ordinary website request metadata. These public pages use no analytics, remote fonts, forms or sign-in scripts.

Retention and deletion

A fixed retention period for Google results, exports and backups has not been established. Authorization duration is separate from data retention.

Saved items can be deleted in the workspace. To request deletion of local credentials, exports or associated copies, email mail@otishz.com. Deletion of all backups and provider-held copies, and a completion deadline, are not guaranteed.

Revoke future Google access through Google Account connections. Revocation does not delete copies already stored.
